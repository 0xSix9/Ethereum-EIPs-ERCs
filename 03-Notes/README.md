# Technical Notes

This folder is for research that spans multiple proposals or does not belong to a single EIP/ERC entry—for example, comparisons, architecture notes, implementation observations, and lessons learned while experimenting.

## Suggested structure

For each note:

- State the question or design problem.
- Link the relevant EIPs, ERCs, repositories, and documentation.
- Separate verified specification details from personal interpretations.
- Capture trade-offs, assumptions, and open questions.
- Add a date when the information may change over time.

When a note makes a claim about a proposal's status or behavior, link to the official source rather than relying only on summaries.
