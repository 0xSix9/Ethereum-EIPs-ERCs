# Selected EIPs

This folder contains EIPs and improvement proposals I find useful to study as a smart contract developer. It is a curated personal collection, not a complete registry.

## How to document a proposal

For each selected proposal, aim to capture:

- **Official specification:** link to the canonical proposal.
- **Problem:** what limitation or need motivated it?
- **Design:** what changes, and how does it work?
- **Status:** record the current official status and date checked.
- **Developer impact:** what changes for contracts, clients, tooling, or integrations?
- **Compatibility and security:** what assumptions, edge cases, and risks deserve attention?
- **Personal notes:** what is worth testing or investigating further?

Always verify status and technical details against the official source before relying on them.
