# Selected ERCs

This folder contains application-layer standards and contract conventions worth studying for Ethereum and EVM development. It is a curated personal collection, not a complete list of ERCs.

## How to document a standard

For each selected ERC, aim to capture:

- **Official specification:** link to the canonical standard.
- **Use case:** what problem does the standard solve?
- **Interface and behavior:** functions, events, return values, and required semantics.
- **Integrations:** which wallets, protocols, or contract systems can use it?
- **Security caveats:** what the standard does not guarantee, plus implementation-specific risks.
- **Tests and implementations:** compare the specification with real code and test cases.
- **Personal notes:** trade-offs, limitations, and possible DeFi applications.

An interface standard is not a security audit. Check both the specification and the exact implementation you intend to integrate.
